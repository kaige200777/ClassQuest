# 学生自选测试内容功能修复说明

## 问题描述
在教师面板测试参数设置时，勾选了"允许学生自选测试内容"后，学生端登录首页没有显示自选预设测试下拉列表。

## 问题原因
教师面板中"允许学生自选测试内容"复选框的`value`属性设置错误，导致即使勾选了复选框，后端也无法正确识别。

### 错误的HTML代码
```html
<input class="form-check-input" type="checkbox" id="allow_student_choice" name="allow_student_choice" value="false" checked>
```

### 问题分析
1. **复选框value错误**：`value="false"`导致无论是否勾选，都发送false值
2. **后端判断逻辑**：`request.form.get('allow_student_choice') == 'true'`期望接收true值
3. **结果不匹配**：复选框发送false，后端期望true，导致功能失效

## 修复方案

### 修复HTML复选框
**修复前：**
```html
<input class="form-check-input" type="checkbox" id="allow_student_choice" name="allow_student_choice" value="false" {% if last_test and last_test.allow_student_choice %}checked{% endif %}>
```

**修复后：**
```html
<input class="form-check-input" type="checkbox" id="allow_student_choice" name="allow_student_choice" value="true" {% if last_test and last_test.allow_student_choice %}checked{% endif %}>
```

## 功能流程说明

### 完整的工作流程
1. **教师设置** → 勾选"允许学生自选测试内容"
2. **表单提交** → 发送`allow_student_choice=true`
3. **后端处理** → `request.form.get('allow_student_choice') == 'true'`返回True
4. **数据库保存** → Test对象的`allow_student_choice`字段设为True
5. **学生访问** → 调用`/api/current_test_settings`检查设置
6. **前端响应** → 显示测试内容下拉列表
7. **加载预设** → 调用`/api/test_presets_public`获取预设列表

### API端点说明

#### 1. `/api/current_test_settings`
```python
def get_current_test_settings():
    current_test = Test.query.filter_by(is_active=True).first()
    if not current_test:
        return jsonify({'allow_student_choice': False})
    
    return jsonify({'allow_student_choice': current_test.allow_student_choice})
```

#### 2. `/api/test_presets_public`
```python
def get_test_presets_public():
    current_test = Test.query.filter_by(is_active=True).first()
    if not current_test or not current_test.allow_student_choice:
        return jsonify({'presets': []})
    
    presets = TestPreset.query.order_by(TestPreset.created_at.desc()).all()
    return jsonify({
        'presets': [{
            'id': preset.id,
            'title': preset.title
        } for preset in presets]
    })
```

### 前端JavaScript逻辑

#### 检查测试设置
```javascript
function checkTestSettings() {
    fetch('/api/current_test_settings')
        .then(response => response.json())
        .then(data => {
            if (data.allow_student_choice) {
                document.getElementById('testContentDiv').style.display = 'block';
                loadTestPresets();
            } else {
                document.getElementById('testContentDiv').style.display = 'none';
            }
        });
}
```

#### 加载测试预设
```javascript
function loadTestPresets() {
    fetch('/api/test_presets_public')
        .then(response => response.json())
        .then(data => {
            const select = document.getElementById('test_content');
            select.innerHTML = '<option value="">-- 请选择测试内容 --</option>';
            
            if (data.presets && Array.isArray(data.presets)) {
                data.presets.forEach(preset => {
                    const option = document.createElement('option');
                    option.value = preset.id;
                    option.textContent = preset.title;
                    select.appendChild(option);
                });
            }
        });
}
```
